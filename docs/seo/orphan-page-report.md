## Intentional Non-Indexable Routes

| URL pattern                          | Reason                                                  |
| ------------------------------------ | ------------------------------------------------------- |
| `/work/[caseStudySlug]`              | Case-study template only; no verified client proof yet. |
| `/admin*`                            | Private admin surface.                                  |
| `/preview*`                          | Draft/preview surface.                                  |
| `/search*` and filter/query variants | Search-filter pages should not be indexed.              |

No indexable launch page is currently orphaned.
