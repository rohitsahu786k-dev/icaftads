# Measurement Baseline

## Current Baseline Status

No Google Search Console, GA4, Google Business Profile, Google Ads, CRM, call tracking or rank-tracking access was available during this phase.

No search volume, ranking difficulty, competitor traffic or conversion baseline should be stated until owner/tool data is supplied.

## Required Access

Owner should supply:

- Google Search Console access for `icraftads.com`.
- GA4 property ID and access.
- Google Tag Manager container ID, if used.
- Google Ads account access, if active.
- Meta Business Manager/Pixel access, if active.
- LinkedIn Insight Tag, TikTok Pixel or other ad pixels, if used.
- Google Business Profile access, if a real UAE/India profile exists.
- CRM/form destination access.
- Call/WhatsApp tracking setup, if used.
- Existing rank tracker or SEO tool access, if available.

## Baseline Metrics To Capture Before Launch

### SEO Visibility

- Current indexed pages.
- Current organic clicks and impressions.
- Current queries and pages from Search Console.
- Current branded vs non-branded search split.
- Current country split, especially UAE vs India.
- Current Dubai/UAE query visibility.
- Current top landing pages.
- Current crawl/indexing issues.

### Technical SEO

- Core Web Vitals.
- Mobile usability.
- HTTPS/canonical status.
- Sitemap status.
- Robots.txt status.
- 404s and redirects.
- Structured data validity.
- Image/video asset performance.

### Conversion

- Contact form submissions.
- WhatsApp clicks.
- Phone clicks.
- Email clicks.
- Book-a-call clicks.
- Service-page CTA clicks.
- Case-study CTA clicks.
- Lead source and campaign attribution.

### Local SEO

Capture only if a real Google Business Profile exists:

- Business name, category, address/service area.
- Phone number.
- Reviews and rating.
- Local search queries.
- Calls, direction requests and website clicks.
- Map-pack visibility for target terms from Dubai.

## Recommended Launch KPIs

Use directional KPIs only until baseline data exists:

- Indexation of all approved launch pages.
- No critical crawl errors.
- Contact form working.
- Analytics events firing.
- Search Console impressions for launch keyword set.
- Growth in qualified non-branded Dubai/UAE impressions.
- Conversion events from organic and paid landing pages.

Do not promise traffic, lead volume, ranking position or revenue before baseline and campaign evidence exist.

## Tracking Plan

Recommended events:

- `generate_lead` for successful form submission.
- `click_whatsapp`.
- `click_phone`.
- `click_email`.
- `book_call_click`.
- `service_cta_click`.
- `case_study_view`.
- `case_study_cta_click`.
- `download_asset`, if resources are created.

Recommended dimensions:

- Service interest.
- Industry.
- Company size.
- Location/country.
- Lead source.
- Landing page.
- Consent status.

## Reporting Cadence

First 30 days after launch:

- Weekly technical and indexing checks.
- Weekly Search Console query/page review.
- Weekly lead-source QA.

After 30 days:

- Monthly SEO visibility review.
- Monthly content gap review.
- Monthly conversion quality review with owner/sales team.
